# Trading Decision Support Assistant

Аналитический помощник для крипторынка: считает технические индикаторы,
определяет режим рынка, формирует план сделки с обязательным стоп-лоссом
и объясняет каждое число обычным языком.

**Система ничего не исполняет.** Она считает и объясняет; решение принимает человек.

## Текущее состояние — читать перед использованием

Стратегия проверена на исторических данных и **прибыльности не показала**:

| Показатель | Значение |
|---|---|
| Сделок в бэктесте | 36 |
| Доля прибыльных | 44.4% |
| Порог безубыточности | 45% |
| Профит-фактор | 0.93 |
| Максимальная просадка | −6.4R |

Профит-фактор ниже единицы означает, что на проверенном отрезке система теряла.
Разрыв с порогом безубыточности — меньше процентного пункта на выборке в 36 сделок,
то есть результат статистически неотличим от нуля.

**Реальные деньги подключать нельзя,** пока не накоплена статистика бумажной
торговли и профит-фактор устойчиво не превысит 1.

## Из чего состоит

```
engine/
  indicators.py   RSI, MACD, MA/EMA, ATR, Bollinger, ADX — чистый Python
  data.py         загрузка свечей с Binance, запасной источник Bybit
  signals.py      режим рынка, группы подтверждений, построение плана сделки
  risk.py         размер позиции и 16 обязательных проверок перед выдачей
  exchange.py     минимальный размер заявки и шаг количества на бирже
  render.py       карточка сделки и сообщение для Telegram
tests/            67 проверок правил и логики
```

## Запуск

Нужен только Python 3.10+. Внешних библиотек нет намеренно.

```bash
python tests/test_rules.py      # проверить, что правила соблюдаются
python check_data.py            # индикаторы по текущему рынку
python run.py                   # разбор всех монет из конфига
python run.py --tg              # то же + отправка в Telegram
python backtest.py              # прогон стратегии по истории
python min_deposit.py           # с каким капиталом какие монеты доступны
```

Настройки — в `config.json`. Секреты (токены Telegram и GitHub) —
в `secrets.local.json`, который исключён из репозитория.

## Принципы, заложенные в код

**Правила про деньги проверяются кодом, а не текстом.** `risk.py` пересчитывает
условия заново и блокирует сделку при нарушении, независимо от того, насколько
убедительно выглядит обоснование.

**Каждое правило закрыто тестом.** Правило, описанное только словами, может быть
незаметно нарушено при изменении кода. Тест это ловит, комментарий — нет.

**Подтверждения считаются по группам.** RSI, MACD и Bollinger — производные одного
ценового ряда; их совпадение не является независимым подтверждением.

**Частота сделок наращивается охватом рынков, а не смягчением условий входа.**

**Отсутствие сигнала — нормальный результат.** Система молчит, когда не за что
зацепиться, и отказывается торговать в фазе высокой волатильности.

## Ограничения

- Ончейн-данные, новости и сентимент не подключены — работают только цена и объём.
- История для проверки короткая (около 170 дней), выборка сделок мала.
- Стратегия использует общедоступные индикаторы, а такое преимущество на рынке
  быстро исчезает.
